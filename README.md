# RapidRoach Exterminators Website

## Files
- `index.html` — main website page
- `style.css` — responsive premium styling
- `script.js` — mobile navigation, reveal animations, and dynamic year
- `images/logo.svg` — custom logo
- `images/favicon.svg` — favicon
- `images/cockroach-treatment-collage.png` — local pest-control image
- `robots.txt` — crawler instructions
- `sitemap.xml` — XML sitemap

## Before deployment
1. Replace `YOUR-NETLIFY-SITE.netlify.app` in `index.html`, `robots.txt`, and `sitemap.xml` with the real Netlify URL.
2. Review service claims and contact details.
3. Upload the contents of this folder to GitHub or drag the folder into Netlify.
